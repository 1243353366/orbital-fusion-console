# Orbital Browser Lens Privacy Notice

**Effective date:** September 20, 2026

Orbital Browser Lens processes page metadata locally and only after the user gives one-time consent for the active tab. The extension has no server component, analytics, telemetry, advertising, account system, or report-upload endpoint.

The extension may process the active page URL without its query string or fragment, the page title, element counts, and selected security-relevant HTML attributes. It does not access browsing history, other tabs, cookies, browser storage, passwords, form values, page text, network bodies, downloaded files, or other extensions.

A report exists in memory while the popup is open. It leaves the browser only if the user explicitly copies it or downloads it as JSON. Closing the popup clears the in-memory report. The project does not sell, share, transmit, or retain scan data.

The scan is a limited DOM hygiene review. It is not a vulnerability assessment, malware verdict, or guarantee of safety.
